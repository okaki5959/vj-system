CONTROLS GUIDE
Sensitivity — beat detection threshold (low = more reactive)
Cooldown — minimum interval between beats (ms)
Max — force switch if no beat detected (seconds)
Pace — switch visual every Nth beat (1x=fast, 8x=slow)
Flash — screen flash on beat
H: show/hide controls / F: fullscreen / Space: play/pause
